Projects

Ongoing, 2026

MemInject: red-teaming toolkit for memory-augmented LLM agents

A PyTorch library that tests how memory-augmented LLM agents hold up against delayed indirect prompt injection. It implements three injection strategies (direct write, semantic blend, retrieval bias) and a benchmark suite. Evaluation on production-grade agents is in progress.

Mock memory agent: 75% trigger rate (direct write), 67% (semantic blend)
In progress, 2026

Activation steering for deceptive alignment

An experimental pipeline to detect and suppress deceptive alignment in cooperative multi-agent LLM systems using representation engineering: layer-wise linear probing for a deception-related direction, direction learning, and inference-time steering.

Validated end to end on a synthetic testbed; trained multi-agent evaluation is next
Completed, 2025

Cross-robustness of lightweight vision systems

A comparison of adversarial robustness (PGD, FGSM) and natural out-of-distribution corruption in lightweight vision models, which matters for deployment on constrained hardware.

Quantized models lost 14% robust accuracy, against 5% at full precision
